Contributing to Media Metadata Analyzer

Thanks for considering contributing! This project is maintained by Eng. Firas Arafah.

License Note:
This project is not open source. You may use it, but modifications are only allowed via pull requests to this official repository. You may not distribute modified versions outside this repo. By contributing, you agree your changes fall under the same license.

How to Contribute:
1. Fork the repo.
2. Clone your fork: git clone https://github.com/FirasArafah/VideoMetadataAnalyzer.git
3. Create a branch: git checkout -b feature/your-feature
4. Make changes, test locally.
5. Commit: git commit -m "Add feature X"
6. Push: git push origin feature/your-feature
7. Open a Pull Request on the original repo.

What to Contribute:
- Bug fixes
- New features (open an issue first)
- Metadata extraction improvements
- UI/UX enhancements
- Arabic translations
- Documentation

Code Style:
- 2 spaces indentation.
- Clear comments.
- Keep functions small.

Issues:
Open an issue on GitHub with details.

Thank you!
